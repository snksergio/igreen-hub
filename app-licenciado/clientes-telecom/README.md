# Clientes telecom

O novo card da lista de clientes telecom do app do licenciado: a lista, o resumo da promo de portabilidade e as sheets de PRO, bônus, rastreio e ações.

Cópia de o canvas "iGreen · Clientes telecom" (https://claude.ai/artifact/A5Tv7kxQZq8QnUTziEL4Fv) e a página "Clientes telecom" (https://claude.ai/artifact/Eu6vdRRjNmYAEnR33fGyK2) do Claude (versões de 2026-11-10). O original continua lá e é a fonte: ajustes são feitos nele e copiados de novo para esta pasta.

Cada página mostra as telas nas posições do canvas, em fundo escuro: arraste para mover, Ctrl + roda do mouse (ou Ctrl + e Ctrl −, ou pinça no celular) para zoom, dois cliques para focar uma tela, ← → para passar de tela em tela e "Ver tudo" para ver a página inteira. Um link com `#NomeDaTela` abre já focado nela.

As imagens das telas estão em `assets/`, com o nome do arquivo igual ao do canvas. As notas de bastidor do canvas (os post-its) não vieram; os títulos das linhas vieram.
