# Canvas Uber e iFood

O canvas de Uber e iFood no app iGreen como no Claude: o estudo, a home com os banners, o crédito com cashback, a conta conectada e a visão com parceria.

Cópia de o canvas "iGreen · Uber e iFood no app" (https://claude.ai/artifact/5mdgUp7xB7EiRNk15KmUBn) do Claude (versões de 2026-11-10). O original continua lá e é a fonte: ajustes são feitos nele e copiados de novo para esta pasta.

Cada página mostra as telas nas posições do canvas, em fundo escuro: arraste para mover, Ctrl + roda do mouse (ou Ctrl + e Ctrl −, ou pinça no celular) para zoom, dois cliques para focar uma tela, ← → para passar de tela em tela e "Ver tudo" para ver a página inteira. Um link com `#NomeDaTela` abre já focado nela.

| Página | Endereço no hub |
|---|---|
| Fluxo proposto | https://igreen-hub.pages.dev/super-app/canvas-uber-ifood/index.html |

As imagens das telas estão em `assets/`, com o nome do arquivo igual ao do canvas. As notas de bastidor do canvas (os post-its) não vieram; os títulos das linhas vieram.
