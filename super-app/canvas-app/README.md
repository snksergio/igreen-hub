# Canvas do app iGreen

As telas do app iGreen como no canvas do Claude: Home iGreen, Eletroposto, login, telecom e pagamento, Cadastro Pay e loja, com zoom, arrastar e foco em cada tela.

Cópia de os canvas "Header Eletroposto — 24 propostas" (https://claude.ai/artifact/5fVEVwo14fpjPfWpdqmxba) e "iGreen · Versões anteriores" (https://claude.ai/artifact/RjKB7sPDWC1HPJLyczztRm) do Claude (versões de 2026-11-10). O original continua lá e é a fonte: ajustes são feitos nele e copiados de novo para esta pasta.

Cada página mostra as telas nas posições do canvas, em fundo escuro: arraste para mover, Ctrl + roda do mouse (ou Ctrl + e Ctrl −, ou pinça no celular) para zoom, dois cliques para focar uma tela, ← → para passar de tela em tela e "Ver tudo" para ver a página inteira. Um link com `#NomeDaTela` abre já focado nela.
