# Login do Super App

O fluxo completo de login do Super App: abertura com biometria, boas-vindas, login por CPF, primeiro acesso, cadastro do Eletroposto, aparelho novo e ajuda de segurança. À esquerda ficam os fluxos; à direita, as telas do fluxo escolhido. Os botões dentro do celular funcionam, e a barra "Simular" embaixo do celular preenche os dados de teste. Todos os dados são fictícios.

Cópia de snksergio/login-superapp (commit 4e43f84). O original continua lá e é a fonte: ajustes são feitos nele e copiados de novo para esta pasta.

As três explorações do login por biometria (07/10) vieram da pasta de trabalho do projeto no Claude, onde estavam antes do fluxo completo; não estavam no repositório. Ficam no acervo "Explorações".
