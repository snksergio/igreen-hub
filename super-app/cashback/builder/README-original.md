# Cashback iGreen · protótipo e apresentação

Proposta de UX para o pagamento com cashback no app do cliente iGreen: do problema ao protótipo navegável. Feita pelo Sergio Vieira (UX), com a ajuda de agentes de growth.

> **É um protótipo.** As regras de cashback, os valores, os clientes e os telefones são fictícios, só para ilustrar. Nada aqui é regra oficial nem produto lançado.

## O que tem aqui

| Arquivo | O que é |
|---|---|
| `index.html` | A apresentação: 21 slides e 3 de apêndice, com animação |
| `prototipo/prototipo-cashback.html` | O protótipo navegável, com 32 fluxos |
| `telas/` | Capturas das telas do protótipo usadas na apresentação |
| `img/` | Ilustrações 3D do projeto |

## Como abrir

Baixe o repositório e abra `index.html` no Chrome ou no Edge.

| Na apresentação | Como |
|---|---|
| Navegar | Setas, espaço, Page Up e Page Down; no celular, deslizar |
| Notas do apresentador | Tecla N |
| Tela cheia | Tecla F |
| Abrir o protótipo | Botão "Abrir o protótipo", nos slides 9 e 20 |

No protótipo, a lista da esquerda escolhe o fluxo e a da direita, o passo.
