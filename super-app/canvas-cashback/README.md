# Canvas do cashback

O canvas do cashback como no Claude: pagamento universal, os topos do Retorno iGreen e o app com home, faturas e pagamento, com zoom, arrastar e foco em cada tela.

Cópia de o canvas "iGreen · Fluxo de cashback" (https://claude.ai/artifact/MJxs617cnas6naGbJDNZsD) do Claude (versões de 2026-11-10). O original continua lá e é a fonte: ajustes são feitos nele e copiados de novo para esta pasta.

Cada página mostra as telas nas posições do canvas, em fundo escuro: arraste para mover, Ctrl + roda do mouse (ou Ctrl + e Ctrl −, ou pinça no celular) para zoom, dois cliques para focar uma tela, ← → para passar de tela em tela e "Ver tudo" para ver a página inteira. Um link com `#NomeDaTela` abre já focado nela.
